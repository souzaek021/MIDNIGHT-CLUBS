# MIDNIGHT CLUBS

Projeto web de eventos e ingressos.

## Estrutura

- `index.html` — página inicial
- `Assets/` — imagens
- `Css/` — estilos
- `Js/` — JavaScript
- `data/` — dados dos eventos
- `Pages/` — páginas internas
