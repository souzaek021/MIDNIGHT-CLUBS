# MIDNIGHT-CLUBS

Projeto acadêmico de plataforma de eventos, desenvolvido com HTML, CSS e JavaScript.

## Estrutura
- `html/index.html` — página inicial
- `Pages/eventos.html` — eventos
- `evento.html` — detalhe do evento
- `comprar.html` — compra
- `cadastrar-ingresso.html` — cadastro do ingresso
- `ingressos.html` — ingressos cadastrados
- `Pages/entrar.html` — entrada
- `Pages/gestao.html` — painel de gestão
- `Pages/clientes.html` — clientes
- `Pages/vendas.html` — vendas
- `Css/` — estilos principais
- `Js/` — JavaScript
- `Data/` — dados dos eventos

O menu de três pontos no canto superior direito contém apenas as áreas do SISTEMA: Painel de Gestão, Clientes e Vendas.
